# NEON DESCENT

Киберпанк‑экшен от первого лица прямо в браузере: неоновые улицы, подземелья, дроны и корпоративная охрана. Игра написана на TypeScript с Three.js и не требует установки.

**▶ Играть:** https://neon-descent-game.vercel.app

## Возможности

- **Хаб «Нексус»** — отправная точка, откуда игрок попадает на уровни.
- **Семь локаций:** Нижний город, Подземка, Промзона Неон‑Док, Небесная башня, Тёмный Лес, Заснеженные Горы и Древнее Подземелье.
- **Арсенал:** кибер‑пистолет, неон‑ПП «Шквал», дробовик «Гроза», энерговинтовка «Призма», штурмовая винтовка «Вихрь», плюс гранаты и грави‑пушка, которая захватывает и швыряет бочки и отталкивает всё вокруг импульсом.
- **Враги:** уличные гопники, корпоративная охрана, боевые дроны, тяжёлые штурмовики, мутанты, авто‑турели и босс CORE‑9.
- **Квесты** с журналом заданий.
- **Прокачка** персонажа (здоровье, урон, скорость) и оружия (урон, магазин, перезарядка, скорострельность, точность).
- **Смена дня и ночи** и погодные эффекты.
- **Сохранения** в нескольких слотах плюс автосохранение. Они хранятся в браузере (`localStorage`).
- **Кооперативный мультиплеер** по коду комнаты: игроки соединяются напрямую через WebRTC (PeerJS), без собственного сервера.

## Управление

| Клавиша | Действие |
|---|---|
| `W` `A` `S` `D` | Движение |
| Мышь | Обзор |
| Левая кнопка мыши | Стрельба; с грави‑пушкой — захватить / бросить бочку |
| Правая кнопка мыши | Импульс грави‑пушки |
| `Shift` | Бег |
| `Space` | Прыжок |
| `R` | Перезарядка |
| `1`–`5` / колесо мыши | Смена оружия |
| `G` | Бросить гранату |
| `V` | Грави‑пушка вкл/выкл |
| `F` | Фонарик |
| `E` | Взаимодействие |
| `Tab` | Журнал квестов |
| `Esc` | Пауза |
| `F11` | Полный экран |

## Мультиплеер

1. Один игрок выбирает в главном меню **«Мультиплеер»** и создаёт комнату. Игра покажет её код.
2. Остальные вводят этот код и подключаются.

Соединение идёт напрямую между браузерами. Если сеть блокирует WebRTC (строгий NAT, корпоративный файрвол), подключиться может не получиться.

## Запуск для разработки

Нужен [Node.js](https://nodejs.org/) версии 20.19 или новее.

```bash
npm install      # установить зависимости
npm run dev      # dev-сервер с горячей перезагрузкой: http://localhost:5173
```

Другие команды:

```bash
npm run build      # проверка типов и production-сборка в папку dist/
npm run preview    # локально открыть собранную версию
npm run typecheck  # только проверка типов TypeScript
```

## Деплой

Проект подключён к [Vercel](https://vercel.com/). Каждый пуш в ветку `main` автоматически собирается и выкладывается на https://neon-descent-game.vercel.app. Пуш в любую другую ветку даёт отдельную превью‑ссылку, основной сайт при этом не меняется.

## Технологии

- [Three.js](https://threejs.org/) — 3D‑графика
- [PeerJS](https://peerjs.com/) — P2P‑мультиплеер через WebRTC
- [Vite](https://vite.dev/) — сборка и dev‑сервер
- TypeScript

```

├── world/         хаб, процедурный город и уровни (levels/)

├── ui/            меню
├── data/          параметры оружия, врагов и квестов
└── types/         общие типы
```
